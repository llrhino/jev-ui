# JEV-UI

**Jev**（TypeSafe AI の「System One / 判断モデル」）を、コードを書かずにフォームで試せるローカル用のプレイグラウンドです。

Jev はふつうのチャットAI（文章を書くAI）とは違い、**「渡した内容(state)について、決めておいた質問(questions)に型付きで答える」** モデルです。答えは次の3種類:

| 種類 | このアプリでの呼び方 | 返ってくるもの |
| --- | --- | --- |
| `choice` | 選択肢から1つ選ぶ | 各選択肢の確率（合計100%）＋ 確信度 |
| `score` | 段階で評価する（点数） | 段階に沿った加重スコア＋分布＋確信度 |
| `noul` | はい / いいえ で答える | 「はい」である確率（0〜1）。※確信度は無し |

このUIは、左に**入力フォーム**、右に**実際に送られるJSON**を並べて表示します。フォームを触るとJSONがその場で変わるので、「どんな入力がどんなリクエストになるか」を見ながら学べます。結果も、人が読みやすいビジュアルと、返ってきた生JSONの両方で確認できます。

## 使い方

### 1. APIキーを設定する

Jev の APIキーが必要です（[TypeSafe AI](https://www.typesafe.ai/) で発行）。

```bash
cp .env.example .env
# .env を開いて TYPESAFE_API_KEY にあなたのキーを貼り付ける
```

キーは開発サーバのプロキシ側だけで使われ、**ブラウザ（クライアント）には送られません**。

### 2. 起動する

```bash
npm install
npm run dev
```

表示された `http://localhost:5173` をブラウザで開きます。

### 3. 試す

1. 上部の「**まず例から試す**」からプリセットを選ぶと、入力が自動で埋まります。
2. 右側の「送られるデータ(JSON)」で、実際のリクエスト内容を確認できます。
3. 「**実行する**」を押すと、下段に結果（わかりやすい表示＋返ってきたJSON）が出ます。

> APIキーが未設定のまま実行すると、結果欄に「キーが未設定です」というエラーが表示されます（.env を設定して開発サーバを再起動してください）。

## 仕組み（技術メモ）

- **Vite + React + TypeScript**、スタイルは素のCSS。
- ブラウザは同一オリジンの `POST /api/jev` を叩き、Vite の開発サーバがそれを `https://api.typesafe.ai/v1/systemone` に中継します。この中継時に `Authorization: Bearer <キー>` を付与します。
  - これにより **CORS を回避** し、かつ **APIキーをクライアントに露出させない** 構成になっています。
  - この仕組みは `npm run dev`（開発サーバ）でのみ動きます。`npm run build` で作る静的ビルドにはプロキシが含まれない点に注意してください（今回はローカル利用が目的です）。

## Jev API の形（参考）

リクエスト:

```json
{
  "model": "jev-latest",
  "state": "二重請求されて怒っている、というお客様からの連絡",
  "questions": {
    "topic": {
      "type": "choice",
      "instructions": "この問い合わせは何についてですか？",
      "criteria": { "billing": "お金・請求の問題", "bug": "製品の不具合" }
    },
    "urgent": { "type": "noul", "instructions": "今すぐ人間が対応すべき？" }
  }
}
```

レスポンス（実物の例）:

```json
{
  "model": "jev-1.13.0",
  "answers": {
    "quality": {
      "type": "score",
      "score": 2.92,
      "confidence": 0.89,
      "legend": { "0": "内容がなく参考にならない", "3": "かなり参考になる", "4": "非常に参考になり具体的" },
      "probabilities": { "0": 0, "1": 0, "2": 0.11, "3": 0.86, "4": 0.03 }
    }
  },
  "usage": { "input_tokens": 453, "output_tokens": 17 }
}
```

ポイント:

- `score` は各レベルの確率(`probabilities`)を重み付けした値（例: 2.92 ＝ ほぼレベル3）。
- `probabilities` は**レベル番号をキーにしたオブジェクト**（choice では選択肢キーがキー）。
- `legend` に各レベル/選択肢の説明が同梱される。`choice`/`score` には `confidence` が付き、`noul` には付かない。
